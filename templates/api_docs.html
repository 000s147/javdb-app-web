📘 API 文档

本文档为 Javdb App 开放接口的用法说明，可直接用于前端联调或第三方集成。 所有接口默认返回 JSON（除 /api/image 返回二进制图片）。

🌐 通用约定
  • Base URL： http://<host>:<port>（默认 http://localhost:9560）
  • 响应格式： {"success": 1|0, "data": {...}, "message"?: "..."}
  • 鉴权： 后端 token 由 api.py 自动维护，前端无需传 token
  • 分页： 统一使用 page + limit
  • 说明：
    • type 和 movie_type 参数代表 all 全部 / 0 有码 / 1 无码 / 2 欧美 / 3 FC2 / 4 动漫，但搜索页的 type 参数代表 movie 影片 / actor 演员 / code 番号 / list 清单 / series 系列 / maker 片商 / director 导演
    • sort_by 参数代表 update 更新时间 / release 发布时间 / score 评分 / hit 热度 / want_watch_count 想看人数 / watched_count 看过人数 / digit 番号 / create 创建时间
    • movie_filter_by 和 filter_by 参数代表 all 全部 / can_play 可播放 / magnets 含磁链 / subtitle 含字幕 / single 单体影片
    • order_by 参数代表 desc 倒序 / asc 正序
    • base_tags 和 filter_tags 参数代表 p 可播放 / m 可下载 / c 含字幕 / s 单体影片 / i 含预览图 / v 含预览视频，使用 英文逗号 分隔多个标签
    • other_tags 和 tags 参数代表标签id的集合，使用 英文逗号 分隔多个标签
    • 短评的 period 参数代表 latest 最新 / weekly 上周热评 / monthly 月度热评 / quarterly 季度热评 / yearly 年度热评 / all 全部热评
    • 排行榜的 period 参数代表 daily 日榜 / weekly 周榜 / monthly 月榜 / actor_monthly 演员月榜
