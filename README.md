# javdb-app-web

基于 Python Flask 构建的 JavDB 第三方现代化 Web 客户端。

项目封装了官方安卓客户端 API 的请求逻辑（包含自动签名与 Token 刷新），并提供了极其清爽、现代的 Web 界面。支持全面的影片、演员、系列浏览，个人收藏管理，以及高级的以图识图、图片解密代理和在线视频预览功能。

------

## 🎉 完整功能介绍

### 1. 🎬 影片浏览与详情

- **全维度列表**：支持浏览“最新上架”、“Top250”、“看热播”、“排行榜”等不同维度的影片列表。
- **类别筛选**：支持“类别”标签多选筛选，按“有码/无码/欧美/FC2/动漫”筛选，并支持按年份、月份、时间等排序。
- **影片详情**：
  - 展示高清封面、标题、发行日期、时长、评分、演员、导演、系列、片商、类别等完整信息。
  - **磁力链接**：自动解析并展示磁力链接，支持一键复制，高亮显示 HD/字幕标签。
  - **在线预览**：集成 Hls.js 播放器，支持影片预告片的 m3u8 流媒体直连播放，以及大图预览（灯箱画廊）。
  - **相似推荐**：自动展示“TA还出演过”和“你可能也喜欢”的影片。
  - **相关清单**：展示该影片被收录在哪些用户清单中。

### 2. 🔍 全功能搜索

- **多维度搜索**：支持搜索影片、演员、番号、清单、系列、片商、导演。
- **关键词高亮**：搜索结果中自动高亮匹配的文字（如搜索“HUNBL”，标题中会进行高亮显示）。
- **高级筛选**：影片搜索支持按“分类/属性（可播放、含磁链、含字幕等）/排序（相关度、发布时间、评分等）”进行二次筛选。

### 3. 🎭 演员与人物

- **分类浏览**：支持按“推荐”、“有码(女/男)”、“无码”、“欧美(女/男)”浏览演员。
- **精细筛选**：女演员支持按“年龄、身高、罩杯、胸围、腰围、臀围”等极其精细的维度进行筛选。
- **演员主页**：展示演员头像、姓名、三围、出生地等基础资料，以及出演的所有作品、相关标签等。

### 4. 🏢 系列、片商与导演

- **系列**：支持按“番号（字母）”、“有码/无码/欧美/动漫”等分类浏览系列合集。
- **片商与导演**：支持查看有码/无码/欧美/FC2/动漫 等类型的片商和导演，进入详情页可查看其全部作品。

### 5. ⭐ 我的收藏与个人中心

- **个人中心**：查看账号信息、VIP 状态、观影统计（想看/看过）、推广信息等。
- **清单管理**：支持创建自定义清单，支持对清单进行重命名、删除、公开/私密设置。
- **收藏同步**：完美同步官方账号的收藏数据，包括：
  - 收藏的演员、清单、番号、系列、导演、片商。
  - 支持批量取消收藏操作。
- **互动记录**：“我的想看”和“我的看过”，自动同步您的评分与短评。

### 6. 🛠️ 进阶工具

- **以图识图**：支持拖拽、粘贴、URL 上传图片，通过内置代理自动识别图片中的影片或演员。
- **聚合短评**：浏览“最新、上周、月度、季度、年度”的热门短评，支持点赞互动。
- **往期佳片**：按周期查看历史精选的 10 部佳片。
- **AV资讯**：浏览官方发布的 AV 行业资讯文章。
- **智能图片代理**：内置图片解密代理，自动处理部分加密或残缺的图片，保证封面 100% 正常加载。
- **自动签名与保活**：请求层自动生成 `jdsignature`，Token 失效后自动无感重登，无需手动刷新。

## 📖 详细使用指南

### 1. 基础浏览

- **全局导航栏**：顶部导航栏包含所有核心模块（排行榜、类别、演员、系列等）。鼠标悬停在带有下拉箭头的菜单上，会自动展开子菜单。
- **高效翻页**：所有列表页底部均配有分页组件，您可以直接输入页码跳转到指定页，或者使用“首页/尾页”按钮快速定位。

### 2. 找片与搜人

- **顶部搜索框**：
  - 点击左侧的下拉菜单，选择搜索类型（如“🎬 影片”、“🌟 演员”、“🧲 磁链”）。
  - 输入关键词后按回车或点击放大镜即可搜索。
  - 点击搜索框右侧的“🖼️”图标，可以唤起“以图识图”功能。
- **筛选按钮**：在“类别”、“演员”、“系列”等页面的顶部，选择不同的筛选条件（如年份、排序、三围等），页面会自动刷新，无需点击搜索按钮。

### 3. 互动与收藏

- **想看 / 看过**：在影片详情页右侧，点击“想看”或“看过”按钮。点击后会变为实心的状态（如“已想看”），再次点击即可取消。
- **加入清单**：在影片详情页点击“加入清单”，可以勾选已有清单或即时创建一个新清单并将影片加入其中。
- **收藏演员**：在演员详情页点击“⭐ 收藏”，即可加入“我的收藏”。

### 4. 以图识图

1. 点击导航栏的“🖼️”识图按钮，或直接访问 `/search_image`。
2. 将本地图片拖拽进虚线框，或直接使用 `Ctrl+V` 粘贴图片、粘贴图片 URL。
3. 预览确认后，点击“搜索图片”，即可自动检索相似影片或演员。

### 5. 更换 API 域名

如果官方 API 连接不稳定，您可以打开 `config.py` 文件，修改 `API_HOST` 的值（代码中已内置了 3 条推荐线路，注释掉旧的，取消注释新的即可），然后重启服务。

## 🚀 部署与运行

### 1. 环境要求

- Python 3.8 及以上

### 2. 安装依赖

bash

```
pip install requests flask
```

### 3. 配置项目

打开根目录下的 `config.py` 文件，填入您的 JavDB 账号信息：

python

```
# Javdb 用户名
USERNAME = "your_username"
# Javdb 密码
PASSWORD = "your_password"

# 本地服务端口，默认 9560
PORT = 9560
```

### 4. 启动服务

bash

```
python app.py
```

启动后，在浏览器中访问 `http://127.0.0.1:9560` 即可看到页面。

*(注：项目首次请求 API 时会自动在根目录生成一个 `javdb_token.json` 文件用于缓存登录凭证。)*

## ❓ 常见问题 (FAQ)

**Q: 获取数据失败或提示 Token 无效？**
A: 请确认 `config.py` 中的账号密码正确。

**Q: 部分封面图片加载不出来？**
A: 本项目使用解密APP图片功能（`/api/image`），图片加载速度会比网页版图片快且无水印，个别图片加载不出来，原因可能是网络错误或超时问题，也可能是该图片不存在或请求错误。

**Q: 视频无法播放？**
A: 预览视频大多为 `m3u8` 格式，本项目使用 `Hls.js` 播放。请确保您的浏览器支持（现代浏览器基本都支持），并检查是否因网络原因导致获取 `m3u8` 切片超时。
