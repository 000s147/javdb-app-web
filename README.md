使用**Flask**开发

首次运行需在**config.py**文件设置你的**javdb**的**用户名**和**密码**，否则无法获取数据。

另外默认端口为**9560**，可自行修改。

#### 运行程序

```bat
python app.py
```
#### 访问
```bat
http://127.0.0.1:9560
```
